# DailyKart
Multi-vendor ecommerce marketplace for customers, vendors and administrators.

## Major Modules
- Authentication & OAuth
- User Profile Management
- Product Catalog
- Category Management
- Product Search Engine
- Advanced Filters
- Shopping Cart
- Wishlist
- Coupon System
- Checkout System
- Razorpay / Stripe Integration
- Order Tracking
- Inventory Management
- Vendor Dashboard
- Admin Dashboard
- Customer Reviews
- Product Ratings
- Sales Analytics
- Invoice Generation
- Notification Center
- Returns & Refunds
- Address Book
- Vendor Onboarding
- Commission Management
- Tax Management
- Promotions & Banners
- Audit Logs
- Support Tickets
- Fraud Monitoring
- API Management

## Stack
React + Next.js + Tailwind-ready UI architecture, Node.js + Express, PostgreSQL, JWT + OAuth, Docker, Git, Vercel/Render.

## Local Setup
```bash
cd backend
npm install
npm run dev
```
In another terminal:
```bash
cd frontend
npm install
npm run dev
```

See `docs/API.md`, `docs/ARCHITECTURE.md`, `docs/DEPLOYMENT.md`, and `docs/PAGES.md`.
